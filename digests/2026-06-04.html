Technical

  • Parity Technologies has published polkadot-unstable2604-rc4, a pre-release version of the Polkadot SDK. This release is for testing only and not recommended for production. Key changes include: fixes for statement network peer metrics, doubled max memory allocation on block import, updated async backing documentation, fixes for runtime upgrade tests, updated wasmtime to 36.0.7, improvements to statement-store (including bounded eviction maps, flooding detection, and topic affinity for light clients), enhancements to the experimental collator protocol, increased relay-chain block size limits on test runtimes, support for Geth-compatible state overrides in eth_call, and many other bug fixes and optimizations across the node, runtime, and developer tooling. Several breaking changes and new APIs are included, especially for parachain and runtime developers (via github).
  • Parity Technologies highlighted the efficiency of Polkadot's light clients, which verify state using cryptographic proofs and block headers, enabling mobile wallets built with PAPI and smoldot to securely verify accounts without storing the full chain history (via x).
