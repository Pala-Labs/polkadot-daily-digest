Technical

  • Polkadot JAM is transitioning its virtual machine (PVM2) to be fully standard compliant with the RISC-V instruction set architecture, moving away from a custom ISA. This change enables direct use of industry-standard tools like the Spike testsuite, improves security through broader scrutiny, and opens the door to running Polkadot JAM on real RISC-V hardware. Internal benchmarks show the new PVM2 matches the performance of the previous custom implementation and is 2x faster than PolkaVM. Additional crypto performance improvements of ~10–20% are in progress but not yet published (via forum).

  • Parity will open source several new proof-of-concept projects ahead of the upcoming Web3 Summit, including ticketing, point-of-sale systems, and AI-assisted developer tooling. Infrastructure updates introduce new protocols—Capacity, Levity, and Nominality—focused on scalable message passing, DNS-like namespaces, and individuality mechanisms. All proofs of concept will be made available on Github for community experimentation and feedback (via forum).

  • Parity highlighted Polkadot’s modular architecture, emphasizing that its separation of execution domains allows each rollup chain to define its own logic, governance, and state, in contrast to the constraints of monolithic chains (via x).
