Technical

  • Polkadot JAM is transitioning its PVM2 instruction set to be fully standard-compliant RISC-V, moving away from custom ISAs. Internal benchmarks show the new standard RISC-V implementation matches the performance of the previous custom version and is about 2x faster than PolkaVM. This change enables use of industry-standard tools like Spike for testing, improves security, and opens the door to running on real RISC-V hardware. The post also notes that PolkaVM's current branding as RISC-V is technically a trademark violation, as it is not fully standard-compliant (via forum).

The suggested change aims to improve repository navigation and contributor experience by reserving Issues for concrete tasks and using Discussions for broader community input (via forum).
