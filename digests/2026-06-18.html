Technical

  • cargo-pvm-contract, a Rust SDK for writing smart contracts targeting PVM and running on Polkadot via pallet-revive, has reached a public preview stage. The SDK offers two authoring styles (macro and DSL), both compatible with Solidity’s ABI and storage, enabling direct use of Ethereum tooling and cross-contract calls. Early benchmarks show the Rust SDK DSL produces PVM bytecode about a third smaller than Solidity (PVM) for token contracts, with macro mode in a similar size range. The SDK is not yet 1.0, with features like deeper storage composition and reentrancy guards still in development (via Polkadot Forum Article).
  • Polkadot SDK released patch version polkadot-stable2512-6 (tagged as polkadot-v1.21.6), updating several runtime crates including cumulus-pallet-xcmp-queue, collectives-westend-runtime, and asset-hub-rococo-runtime. The release includes a performance improvement for xcmp-queue by storing bytes in the channel status, and was built with Rust 1.88.0. No new binaries or Docker images are provided for this patch (via GitHub).
