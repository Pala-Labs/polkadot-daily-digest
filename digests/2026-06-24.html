Governance

  • Polkadot OpenGov has two new referenda, #1909 and #1910, proposing updates to staking parameters. Technical

  • Resolc v1.3.0 has been released, introducing the "newyork" (NEW Yul OptimizeR Kit) optimizer, which sits between Yul and LLVM. This update brings typical Solidity contract code size reductions of -20% to -50% compared to previous resolc versions without the optimizer. The improvements allow Solidity contracts JITed via PVM to approach or even match the code size of well-optimized Rust contracts, potentially increasing transaction throughput due to reduced overhead (via forum - Cyrill).

Ecosystem

  • Plaza Names is now live, providing a new interface for discovering .dot names on Polkadot Hub. The platform allows users to search for .dot names, check dotNS rule tiers, verify ownership via Asset Hub, and assess name availability. The current version is read-only; wallet registration and .dot registration for token launches are not yet enabled (via forum - Elvis).
