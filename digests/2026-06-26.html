Report

Governance

  • Referenda #1909 and #1910 are live for community vote, proposing major staking overhauls: removal of nominator slashing, reduction of the unbonding period to 48 hours, stronger validator incentives, and a shift to 0% commission (validators earn via self-stake instead). These are described as among the biggest UX upgrades to Polkadot staking to date, with Bifrost noting that if Ref 1910 passes, vDOT benefits directly from lower staking risk and a shorter unbonding window (via forum - Pala_Labs).
  • A community debate is ongoing regarding the proposed $JAMKB resource token for the JAM protocol. Proponents clarify it is not a new competing coin but would be 100% owned by the DOT DAO and serve a technical function that DOT alone cannot fulfil. The debate centers on whether state footprint should be a perpetual holding or a metered flow, with arguments presented for both models and their implications for value capture and resource allocation (via forum - Pala_Labs, forum - batbayar).
  • QuantumScan, an open-source PQC vulnerability scanner for Substrate/Polkadot, has been delivered and is seeking ~2,000 DOT from the Treasury as retroactive recognition for work already shipped, plus a technical article deliverable. The tool detects post-quantum cryptography vulnerabilities in Substrate codebases and is live at quantumscan.io, with all technical deliverables except the article completed prior to the W3F Grants Program discontinuation (via forum - gaiabio12-design).
  • A draft proposal for a validator monitoring tool has been shared for community feedback ahead of a potential treasury referendum. The tool would alert nominators in real time to validator commission changes, identity changes, and compliance drift, aiming to improve nominator safety. The foundation is open source and self-hostable, with planned features including alert delivery, multi-chain support, and a minimal web UI (via forum - wes).

Technical

  • QuantumScan v1.9.1 is live, providing a CLI scanner for post-quantum cryptography vulnerabilities in Substrate/Polkadot codebases. It detects 19 Substrate-specific patterns across five categories, including consensus, pallet crypto, XCM, ink! contracts, and workspace dependencies. The tool is open source (MIT), with a public endpoint and Docker image available, and has completed 233+ public repo scans (via forum - gaiabio12-design).
  • A new Substrate-based blockchain has been announced, described as a Polkadot SDK fork with tech debt removed, running on RISC-V instead of WASM. The chain features NPoS with a 2-day unlock period, a DNS system, ephemeral messaging, and a mobile app in closed beta. An airdrop is planned for DOT holders under 20k DOT (via forum - prodigalwon).
