These changes follow the earlier introduction of a minimum self-stake requirement for validators (via Polkadot Forum Article - Gr33nHatt3R, X Posts - paritytech, X Posts - Polkadot).

Technical

  • Substrate4j, a Java client for Substrate-based chains, is nearing completion. It offers static, type-safe runtime access, pure Java cryptography (including SR25519, Ed25519, ECDSA), a complete SCALE module, and is built on the new Polkadot JSON-RPC spec. The client is published to Maven Central and aims to provide a production-grade, developer-friendly tool for interacting with Polkadot, Kusama, and Asset Hub (via Polkadot Forum Article - mhrsalehi).
