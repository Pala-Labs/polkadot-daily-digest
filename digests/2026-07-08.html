Report

Governance

  • Polkadot Asset Hub validator election stall and remediation: On 2026-06-30, the validator election on Polkadot Asset Hub stalled at round 238 (era 2220) after Referendum 1909 lowered ChillThreshold to 32%, triggering a wave of permissionless chilling that removed 67 under-bonded validators. This dropped the achievable election score below the static MinimumScore floor, causing all submitted solutions to be rejected and slashed, freezing validator set rotation, staking rewards, and unbonding. Referendum 1914, fast-tracked via the Fellowship Whitelisted-Caller track, lowered MinimumScore.minimal_stake from 789,555 to 500,000 DOT, unblocking the election and restoring normal era cadence. No user funds were lost, and only two staking-miner deposits were slashed (one already reimbursed via Referendum 1915). The incident highlighted the need for improved simulation, monitoring, and process around staking parameter changes and score floor adjustments. An open question remains on how to redistribute the ~115,350 DOT self-stake incentive budget from the long transition era 2219, which defaults to the DAP buffer in ~84 days unless otherwise decided (via forum - sigurpol).
  • PolkaVision pre-proposal discussion: A community member is seeking feedback on a potential Treasury proposal for PolkaVision, a live visual explorer for the Polkadot ecosystem. The prototype indexes mainnet data hourly and provides an interactive graph of the relay chain and parachains. The proposed Phase 1 would focus on backend reliability, improved visualization, mobile UX, and parachain discovery, with a tentative funding range of $15k–$20k USDC/USDT for 6–8 weeks. Community input is requested on scope, priorities, and evaluation metrics before submitting on-chain (via forum - akhtarshahnawaz).

Technical

  • Nominator slashing removed and unbonding period reduced: Polkadot Referendum 1910 has been enacted, removing slashing risk for nominators and reducing the unbonding period from 28 days to approximately 2 days. Validators retain slashing risk on their own self-stake, maintaining the network’s security model. Some wallet UIs, such as Nova Wallet, have not yet updated to reflect these changes (via forum - OpenShore).
  • Substrate4j Java client nearing completion: Substrate4j, a Java client for Substrate-based chains including Polkadot, Kusama, and Asset Hub, is in its final stages. It offers static, type-safe runtime APIs generated from metadata, pure Java cryptography (SR25519, Ed25519, ECDSA), a robust SCALE module, and a resilient, non-blocking RPC layer. The client and supporting libraries are published to Maven Central, and the project aims to provide production-grade, feature-rich chain interaction for Java developers (via forum - mhrsalehi).
