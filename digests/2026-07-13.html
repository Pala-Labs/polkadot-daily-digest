Technical

  • Pine-RPC, an ETH-RPC compatibility layer built on smoldot, has been introduced to address issues with RPC provider throttling, particularly on Paseo. Pine-RPC allows users to run a self-contained smoldot node server that translates Ethereum RPC calls, supporting both testnet (Paseo Asset Hub) and mainnet (Polkadot Asset Hub) environments, with installation options via npm or Docker. The tool enables Ethereum tools to interact with Polkadot chains through a local endpoint, with first sync times ranging from 10 to 60 seconds (via Polkadot Forum Article - Nukeme3).
